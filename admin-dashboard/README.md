# Admin Dashboard

Industry-grade React admin dashboard for HRMS system.

## Features

- 🔐 JWT Authentication
- 📊 Dashboard with statistics
- 👥 Employee management
- ⏰ Attendance tracking
- 🏢 Department management
- 💰 Payroll calculation
- 📈 Analytics and insights

## Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Environment Variables

Create a `.env` file:

```
VITE_API_URL=http://localhost:8000
```

## Access

- Development: http://localhost:3000
- Login: admin / admin123

## Tech Stack

- React 18
- React Router v6
- Axios
- Lucide React Icons
- Vite
