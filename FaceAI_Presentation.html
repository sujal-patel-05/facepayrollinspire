🔑 Key Insight

Each face becomes a 512-dimensional mathematical fingerprint (just 2,048 bytes). The model doesn't classify — it maps faces into a shared vector space where distance = dissimilarity.

🔒 Privacy Guarantee

Original image is discarded from memory after embedding extraction. Only the irreversible mathematical vector is stored. No face can be reconstructed.

Deep Learning Architecture

ResNet‑50 — The CNN Backbone

A 50-layer deep Convolutional Neural Network with ~25.6M parameters that transforms a 112×112 face image into a 512-D vector.

🧱 Hierarchical Feature Learning

  • Layer 1: Edges, gradients, basic textures
  • Layer 2: Corners, curves, patterns
  • Layer 3: Eyes, nose, mouth shapes
  • Layer 4+: Holistic face structure & identity

⚡ Skip Connections (Residual Learning)

Output = F(x) + x — learn the residual, not the full mapping. This solves the degradation problem in deep networks.

Training Methodology

ArcFace — Additive Angular Margin Loss

ArcFace (Deng et al., 2019) operates in angular space to create tighter, more discriminative face clusters.

// ArcFace Loss Formula
L = -log( exp(s · cos(θyi + m)) /
       (exp(s · cos(θyi + m)) + Σj≠yi exp(s · cos(θj))) )

// Where:
m = 0.5   // angular margin (radians)
s = 64    // scaling factor

How It Works

  • L2-normalise both features & weights → unit sphere
  • Dot product = cosine of angle between vectors
  • Add angular margin m to the correct class
  • Forces tighter clusters with wider inter-class gaps
Loss FunctionMargin TypeYear
SoftmaxNone—
SphereFaceMultiplicative angular2017

ArcFace ✓Additive angular2019

Why ArcFace Wins

Constant angular margin at all angles — geometrically consistent separation on the hypersphere surface. No training instability unlike SphereFace.

Implementation

InspireFace Engine & Embedding Matching

InspireFace SDK wraps ArcFace + ResNet into a clean session-based API. We use the Megatron model variant for maximum accuracy.

# Initialisation
isf.reload("Megatron")
session = isf.InspireFaceSession(
  isf.HF_ENABLE_FACE_RECOGNITION,
  isf.HF_DETECT_MODE_ALWAYS_DETECT
)

# Face detection + embedding
faces = session.face_detection(image)
embedding = session.face_feature_extract(image, face)

# L2 normalisation
norm = np.linalg.norm(embedding)
embedding = embedding / norm

# Cosine similarity
similarity = np.dot(emb1, emb2) # since ||emb|| = 1

📐 Cosine Similarity Matching

cos(A, B) = A · B / (‖A‖ × ‖B‖)

Since vectors are L2-normalised:
cos(A, B) = A · B (simple dot product!)

✅

Score ≥ 0.6

Identity confirmed, attendance logged

❌

Score < 0.6

Face not recognised, rejected

🔄 Fallback System

If InspireFace fails → automatic fallback to OpenCV Haar Cascade for degraded but functional detection.

🔒 Privacy Architecture

No Image Storage

Face images processed in-memory, then immediately discarded. Only the 512-D embedding vector is persisted as a BLOB.

Mathematically Irreversible

512-D float32 vector → cannot reconstruct the original face. Information is lossy by design.

On-Premise Processing

All AI runs locally. No biometric data sent to cloud. Full data sovereignty.
